# Thynk — director's cut

This document follows the user's scene-by-scene brief, not the previous generic films. The only built-in catalog contains the twenty films below. All share the uncut 54.186-second Thynk narration and the same semantic sequence. User-created copies are separate, explicit additions.

## Visual contract

Purple `#7b2df4`, white `#ffffff`, and tonal purple/white shading only in the films. Original colorful supplied images are retained as source assets; displayed derivatives are purple-white. Prompt hint text is black, as explicitly requested. Large surfaces use 35px corners, small cards and pills 25px. Fullscreen plates and circular data rings are deliberate exceptions. Phone, tablet and desktop UI has no outer border, bezel, black frame, stand or notch. No extra headings, progress rails, brand stickers, marketing slogans or invented product names.

Captions slide vertically into position. Alternate directions use slide down; the others slide up. No caption opacity-only pulses or random word rotations. Large opening and centered product/CTA titles contrast with medium narration and small build-stack captions. Words follow the existing measured word timestamps. Every authored format reserves padding around the composition; graphics scale uniformly, never independently on x/y.

## Sound direction

Only the supplied soft UI pop is used on caption reveals. Whoosh, punch and ding are reserved for specific graphic reveals. Sources are onset-trimmed and peak-normalized individually before cue gains. Caption and graphic cues share the same clock as the picture. Full cue list, measured onsets and levels: `timing/directed-sfx.json`. The original narration file remains unchanged. Delivery mix applies one small static headroom gain, not compression, time stretching, cuts or speech normalization.

## Editor direction

One 48px dark navbar contains the brand, timestamp dropdown, scene dropdown, object edit control, playback switch, format, project and record controls. Nothing sits above it. Navbar height matches the sidebar width. The preview and sidebar share a row and height. Smaller windows scroll the navbar horizontally while the page itself stays in the first fold. Asset folders are traversed recursively, image filenames map to visible semantic slots, and Save as new template produces a persistent copy.
