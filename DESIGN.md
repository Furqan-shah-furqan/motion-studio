# Motion Studio V5 — Thynk director's cut

## V5 generation contract

The first render keeps the source template's authored layout. **Generate** saves queued assets, advances a generation seed, and reassigns scene-aware caption, motion, transition and layout treatments without changing the measured narration or uploaded media. Every source asset must be explicitly assigned: extra references may inform the style without appearing in the final video. The ClipFlow editor interface is reconstructed as procedural layers with lime crop handles and tracked timeline motion based on the supplied first/second reference-frame imagery. Outer/inner screen geometry uses a 35px radius and no device bezel. All selects share the canvas-style option popup.

This document follows the user's scene-by-scene brief, not the previous generic films. The only built-in catalog contains the twenty films below. All share the uncut 54.186-second Thynk narration and the same semantic sequence. User-created copies are separate, explicit additions.

## Visual contract

Purple `#7b2df4`, white `#ffffff`, and pink `#f3a4e8` are the shared brand palette. Original supplied imagery remains unedited in the reference library; displayed derivatives continue to use the intended visual styling. Prompt hint text is black. Large surfaces use 35px corners, small cards and pills 25px. Fullscreen plates and circular data rings are deliberate exceptions. Phone, tablet and desktop UI has no outer border, bezel, black frame, stand or notch. The films share the same four product stories and narration, but each of the twenty templates has a different composition, word-caption motion, scene transition, decorative motion pattern and icon/card treatment.

Captions follow the existing measured word timestamps and safe margins. Their entrances include snap, orbit tracking, cascading clips, split phrases, scale blooms, focus locks and other template-specific movements; none rely solely on opacity changes. Scene transitions use their own masks (such as radial, diagonal, grid, wave and split reveals). Motion textures and card accents use the same violet/white/pink palette. Every authored format reserves composition padding; graphics scale uniformly, never independently on x/y.

## Reference library

The V3 project includes the renamed reference assets grouped by script beat: Intro, ClipFlow, Wireframer, FoodSnap, AR Menu, Tech Stack, Call to Action, and Transitions/B-roll. The editor's Reference Library tab filters by search text, category and media type. Each card can assign a reference image or video/GIF poster to a supported visual slot in the selected film. The original media is retained in `assets/reference-library/`; generated still posters are kept in `_posters/`. The `Asset_Name_Map.md` file records original-to-new filenames.

## Sound direction

Only the supplied soft UI pop is used on caption reveals. Whoosh, punch and ding are reserved for specific graphic reveals. Sources are onset-trimmed and peak-normalized individually before cue gains. Caption and graphic cues share the same clock as the picture. Full cue list, measured onsets and levels: `timing/directed-sfx.json`. The original narration file remains unchanged. Delivery mix applies one small static headroom gain, not compression, time stretching, cuts or speech normalization.

## Editor direction

One 48px dark navbar contains the brand, timestamp dropdown, scene dropdown, object edit control, playback switch, format, project and record controls. Nothing sits above it. Navbar height matches the sidebar width. The preview and sidebar share a row and height. Smaller windows scroll the navbar horizontally while the page itself stays in the first fold. Asset folders are traversed recursively, image filenames map to visible semantic slots, and Save as new template produces a persistent copy.
